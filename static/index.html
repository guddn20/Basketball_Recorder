골대 적용 구간

지정한 림 위치를 사용할 영상 구간입니다. 편집으로 구도가 바뀌면 구간을 나눠 등록하세요.

추적 구간 연결

다른 사람으로 바뀌는 구간이라면 연결을 해제하세요. 이미 확정한 기록은 장면 기록에서 따로 수정할 수 있습니다.

오늘 처음 쓰는 순서

  1. 영상을 추가하세요. 처음에는 30~60초 구간으로 시험하세요. 기록은 자동 저장됩니다.
  2. 선수를 등록하세요. 일시정지 → ‘선수 지정’ → 머리부터 신발까지 전신을 드래그하세요. 같은 선수의 앞·뒤 장면을 추가하면 도움이 됩니다.
  3. 골대를 지정하세요. ‘골대 지정’ → 실제 공격 골대의 림을 가로로 감싸세요. 백보드 전체 대신 림 주변의 작은 영역을 지정합니다.
  4. 분석을 실행하세요. 선수 추적과 골대 주변의 공 움직임으로 슛 후보를 찾습니다. 이동 촬영은 골대 위치를 놓칠 수 있어 고정 촬영부터 권장합니다.
  5. 후보를 검토하세요. 선수·성공/실패·2점/3점을 확인하고 확정하세요. 놓친 장면은 M 키로 직접 추가합니다.
  6. CSV를 저장하세요. 경기 전체가 담기지 않았다면 ‘한 팀 공격’ 또는 ‘하이라이트’를 선택해 미집계 항목을 구분하세요.
자동 분석은 범용 감지 모델과 색상 단서를 사용한 시험 버전입니다. 등번호 OCR, 자동 2·3점 판정, 자동 어시스트·리바운드 판정은 제공하지 않습니다. 슛 후보에는 오탐과 누락이 있으며, 모든 확정은 사용자가 합니다.

브라우저에서 영상이 재생되지 않으면 ‘프레임 모드’를 사용하세요. 프레임 모드는 느린 장면 검토용이며 오디오는 없습니다. 데이터는 프로그램 폴더의 data에 저장됩니다.
